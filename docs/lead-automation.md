# CamGotIT Lead Scout — prototype contract

## Inputs
Authorized/manual leads or first-party website inquiries, when approved. No scraping Nextdoor or extracting personal data from pages.

## Workflow
1. Human identifies a lead in an authorized public or consented channel.
2. Save source, locality, topic, URL only when sharing is permitted.
3. Classify likely services; decide whether issue is remote-eligible or needs in-home help.
4. Produce **a proposed reply**; human checks it before responding from the appropriate Business Page/channel.
5. Record whether a quote is requested, booked, completed, or declined.
6. Convert qualified inquiry to a ticket without duplicating customer contact information.

## Agent limits
Never promise prices beyond published starting rates, no automatic cold DMs, no bypassing platform rules, no customer passwords, no payment/card details, no unapproved bulk messaging. Add a human review gate.

## Future integration
Nextdoor partner APIs may offer public searchable content and posting with explicit API approval. Evaluate eligibility and permissions first; if not approved, keep manual capture.
